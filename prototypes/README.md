# CommerceAgent 桌面端 PNG 原型

`png/` 收录 68 张静态原型，按 1440 × 900 桌面视口渲染，导出为 2880 × 1800 PNG。01–34 保留原编号；35–68 为补充页面和状态。图片使用本地沙箱示例数据，不代表功能已实现。成功、失败、撤回、驳回等图片是可独立查看的演示分支，不是一条连续记录。

| 场景 | PNG 编号与阅读顺序 |
| --- | --- |
| 首期促销主流程 | **02 → 03 → 04 → 23 → 25 → 12**：追问开始日期、生成方案、确认提交、人工审批、复核排期、活动详情。 |
| Agent 查询与方案 | **35 → 36**：切换店铺、拦截旧方案；**38 → 37**：流式查询到只读结果；**39–40**：调价和退款方案；**05、61**：促销和售后规则问答。 |
| 促销校验与再审 | **41–44**：库存 99/100 边界、并发排期冲突、重复确认；**45 或 46 → 47 → 48**：驳回或撤回、V2 修订、再送审；**49–51**：自审、跨店、重复裁决拒绝。 |
| 商品及库存 | **06–09、52–54**：商品列表、详情、库存流水、调价申请、商品资料维护、调价执行成功及复核失败。 |
| 订单与退款 | **15–19、55–60**：订单和退款基础页面、异常处理建议、退款审批快照、重复申请拦截、执行失败、重试中与重试成功。 |
| 经营分析与促销生命周期 | **13–14、20–21、62、65–67**：促销日历与复盘、看板与日报、库存周转与异常、到点生效、到期结束和错过时段。 |
| 系统管理与沙箱 | **22、24–34、63–64、68**：审批与任务、失败恢复、权限与审计、通知、调用失败详情、沙箱管理及非管理员访问拒绝。 |

界面与权限边界以[产品设计](../docs/product-design.md)为准。原有 `design-md.html` 和 `design-md-desktop.png` 仍用于视觉基线参考。
